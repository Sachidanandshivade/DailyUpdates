JavaScript Events Reference Guide Mouse Events: - click: Triggered when an element is clicked. - dblclick: Triggered when an element is double-clicked. - mouseover: Triggered when the mouse pointer enters an element. - mouseout: Triggered when the mouse pointer leaves an element. - mousemove: Triggered when the mouse moves within an element. Keyboard Events: - keydown: Triggered when a key is pressed down. - keyup: Triggered when a key is released. Form Events: - submit: Triggered when a form is submitted. - change: Triggered when the value of an input changes. - input: Triggered every time a user types in an input field. - focus: Triggered when an element gains focus. - blur: Triggered when an element loses focus. Window Events: - DOMContentLoaded: Triggered when the HTML document is fully loaded. - resize: Triggered when the browser window is resized. - scroll: Triggered when the user scrolls. DOM Events
